Kết nối app Lớp học AI

Web học liệu đã được tích hợp sẵn mục Lớp học AI. Phần tương tác trực tiếp chạy bằng Streamlit/Python nên cần một URL app riêng trước khi nhúng vào đây.

  • Netlify chỉ chạy web tĩnh, không chạy trực tiếp file app.py.
  • Sau khi deploy app Streamlit lên Render, Streamlit Community Cloud hoặc VPS, dán URL public vào ô bên dưới.
  • Nếu đang chạy thử trên máy cá nhân, mở trang này bằng URL dạng ?app=https://... hoặc dùng nút Mở riêng sau khi có URL.
Không tải được khung nhúng. Hãy mở app bằng nút "Mở riêng".
